**Banking Management System**

**Project Overview:**
The Banking Management System is a web-based application developed using Python and Django. It provides a centralized platform to manage customer banking information, accounts, loans, bank cards, and health insurance policies.

The application provides a dashboard where customers can view their banking information, while administrators can manage banking records through the Django Admin interface.

**Technologies Used**

Backend: Python, Django

Frontend: HTML, CSS

Database: SQLite

Framework: Django Web Framework

**Features:**

Customer Dashboard

Savings Account Management

Current Account Management

Loan Management

Credit Card Management

Debit Card Management

Health Insurance Policy Management

Individual Account and Loan Details Pages

Admin Panel for Managing Banking Records

User Authentication and Login Protection
